# Uninstalling SpoTUI Theme

To uninstall the SpoTUI theme, simply press 3 in the CLI.


# Run the CLI
### Windows & Linux
```powershell
spotui
```
# Update
After the CLI opens, select "Uninstall SpoTUI" to uninstall the theme.
