# Publishing Your Theme

If you've read the documentation above, you now know how themes work and have probably made one.  
The next step is publishing it so other users can enjoy it!

Publishing is really easy. You just paste the `tui` commands into an input field, attach a screenshot, and do the hardest part: give your theme a name.

## Step-by-step guide

### Step 1: Visit the SpoTUI webpage

Go to [spotui.root.sx](https://spotui.root.sx/).

### Step 5: Success! You have uploaded your first theme!

**Note:** You must restart your Spotify client in order for the latest themes to be fetched from the server.  
Your theme should appear instantly after the restart, with no waiting time.

**Note:** Themes containing broken `tui` syntax, broken screenshot links, etc. are automatically removed every 24 hours.

## Editing or Deleting Your Theme

The ability for users to edit or delete their own themes is not available yet. We are working on it!

Until then, if you want to edit or delete your theme:

1. Open an issue in the [SpoTUI GitHub repository](https://github.com/SkenSMasteR/SpoTUI).
2. Make sure you are logged into GitHub with the same account you used to sign in to the SpoTUI webpage when creating the theme.
3. Explain the changes you want made to your theme, or let us know that you want it removed from the theme browser.
